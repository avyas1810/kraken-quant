# Kraken Quant Research

This repository documents my quantitative research and systematic trading project for Kraken spot markets.

The implementation currently depends on a licensed shared codebase that I am not permitted to redistribute. Consequently, the source code cannot be published here at this stage.

As the project develops, this repository will contain independently publishable material, including:

- Strategy methodology and assumptions
- Backtesting and validation results
- Performance and risk metrics
- Regime-analysis findings
- Research charts and reports
- Live and shadow-trading results
- Independently developed components that do not contain restricted code

No API keys, credentials, proprietary source code, or live trading secrets will be published.
